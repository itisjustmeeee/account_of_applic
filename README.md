# Acc for app
## Сквозной проект по разработке приложений на базе фреймворков

## Назначение

Данный проект представляет собой приложение, которое будет принимать заявки от пользователей с присвоенным статусом, который будет меняться в зависимости от того, в каком состоянии будет находится завяка (новая/в работе/выполнено).<br>
Зявки можно будет отсортировать по категории и статусу

## Целевая аудитория

Целевой аудиторией данного проекта являются люди, у которых возникают какие-либо проблемы повседневного характера, решающиеся ответом в письме на оставленную заявку.

## Предметная область

Предметной областью явялется взаимодействие с клиентами (CRM) и управление клиентским сервисом (Help Desk/ Service Desk)
