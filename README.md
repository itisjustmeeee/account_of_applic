# Acc n' app
## Сквозной проект по разработке приложений на базе фреймворков

## Назначение

Данный проект представляет собой приложение, которое будет принимать заявки от пользователей с присвоенным статусом, который будет меняться в зависимости от того, в каком состоянии будет находится завяка (новая/в работе/выполнено).<br>
Зявки можно будет отсортировать по категории и статусу

## Целевая аудитория

Целевой аудиторией данного проекта являются люди, у которых возникают какие-либо проблемы повседневного характера, решающиеся ответом в письме на оставленную заявку.

## Предметная область

Предметной областью явялется взаимодействие с клиентами (CRM) и управление клиентским сервисом (Help Desk/ Service Desk)

## Основные сущности

- Пользователь
- Заявка
- Категория
- Статус
- Администратор

## Основные функции

### Гость

1. Регистрация
2. Вход

### Пользователь

1. Добавление заявки
2. Присвоение категории при создании заявки
3. Получение ответа на заявку
4. Удаление своей зявки
5. Просмотр своих заявок
6. Просмотр свой заявки по id

### Заявка

1. Создание новой заявки
2. Получение зявки по id
3. Получение всех заявок
4. Удаление заявки
5. Изменение статуса заявки
6. Определение приоритета заявки
7. Добавление ответа админа

### Категория

1. Получение всех категорий
2. Получение категории по id
3. Добавление категории
4. Удаление категории
5. Редактирование категории

### Статус

1. Получение всех статусов
2. Получение статуса по id
3. Создание статуса
4. Удаление статуса
5. Редактирование статуса

### Администратор

1. Просмотр всех заявок пользователей
2. Просмотр полной информации о заявке
3. Изменение статуса заявки
4. Отправка ответа на заявку
5. Удаление заявки пользователя
6. Просмотр списка пользователей
7. Управление категориями
8. Управление статусами

## Структура проекта 
- main.py – точка запуска;
- models/requests.py – работа с заявками;
- models/users.py – работа с пользователями;
- models/category.py – работа с категориями
- models/services.py – функции для работы с классами
- models/statuses.py - работа со статусами
- data/ – JSON-файлы данных;
- tests/ – автоматизированные тесты.
